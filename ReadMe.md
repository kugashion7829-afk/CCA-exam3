## 総括

この度のWebプログラミング演習では、前２回とは明確に差異を持つために取り組みました。

経験が浅いため、演習を通し、どんなメリット、デメリットがあるのかを自身で把握するためでもあります。

### 概要

今回の演習では、できる限り細かく工程を分けて作業を行っていました。

HTMLから始まりCSS、PHPと各ページごとに順に作業を切り分けていました。私自身がPHPにまだ明るくないため、不安がありましたので

出来るだけ細かくすることにより、全体のつながりを意識せず制作することができたと感じています。

良し悪しはあります。全体をイメージしながら作成できるのであればその方が効率的でしょう。

この方法を行ったことにより、以前から苦手としていたCSSのレスポンシブに関して、

ある程度克服できたのではないかなと感じています。

レスポンシブに関しても工程を切り分けるにあたり、セクションやページごとにメディアクエリを用意する方法をとりました。

教科書で習う方法は基本的にメディアクエリは、CSSの後半部分にまとめて記述するものでした。

ですが、セクションごとにメディアクエリを用意したことで、見やすくなり作業しやすくなったと感じました。

その分、デメリットも存在します。共通の記述の管理がしづらくなったことです。後半部分にまとめて記述されている場合は対処が比較的容易ではありますが、

この分割する手法では、少々手間が増えてしまうようにも感じました。ですが前述の通り、書きやすく見やすさを重視するので私はこちらの方が好みだと感じました。



前述した通り、PHPが不得手のため、AIを多用してしまったのが少し心残りです。

悪いことではないのですが、自身の能力の延長線と考えるにはあまりにもオーバースペックです。

この部分とどう折り合いをつけるのかはやはり、まだ自分の中での課題として大きく残りそうです。

ですが、確実に勉強になった部分もあるため、次回以降のWeb制作に活かしていけたらいいと考えています。

### 内容・工夫点

初めに取り組んだのは、headerとfooterのファイルを作るところからでした。

各ページで使う共通ファイルですから予め用意する方が効率的だと考えました。実際、指示書でも最初のうちに作成するよう促されていましたね。

header.phpには基本的なhtmlの<mark>お決まりセット</mark>から<head>タグ,<body>開始タグ,<header>タグ,<main>開始タグを含めた構成になっています。

基本的なstyle.cssやgoogle-fontの指定もheader.phpで行っています。

footer.phpには<main>終了タグ,<body>終了タグ,<footer>タグ,<small>タグ,などが含まれています。

headerに付属しているドロワーメニューのscript.jsもfooter.phpで読み込ませています。
